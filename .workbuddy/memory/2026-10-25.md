# 2026-10-25 分析页「近半年趋势」点柱跳明细 —— 接入

## 做了什么

分析页趋势柱点击原来是占位 toast（`analysis.js onTrendTap` 弹「明细待接入」），
本次接通为：点柱 → 明细页展示该月流水。明细页的月份能力一并接入
（`loadBills` 原来写死当前月，上/下月按钮原来也是「历史月份查询待接入」占位）。

## 关键约束：tab 页跳转不能带参

明细是 tabBar 页，`wx.navigateTo` 打不开、`wx.switchTab` 不收 query。
跨 tab 传月份只能走 `app.globalData` 中转（项目里 `monthSummary` 已有先例）：

```
analysis.wxml 柱子 data-month → onTrendTap 写 globalData.detailMonth
  → switchTab → detail onLoad/onShow 消费 → 清空（一次性）
```

## 实现要点（为什么这么写）

- **onLoad 和 onShow 都要消费**：明细 tab 从没打开过时只有 onLoad+onShow 一次性
  连触发，只在 onShow 消费会导致 onLoad 先加载当前月、再被覆盖（闪一个月）。
  onLoad 先消费可直达目标月；onShow 兜「页面已加载后再跳转」的场景。
- **消费后必须清空**：不清空的话，用户之后自己点「明细」tab 仍会被拽回旧月份。
- **请求序号 `_seq`**：切月是先 setData 乐观切标题再等响应。快速连点 ‹ › 时，
  先发出的旧月份响应晚到会覆盖新月份的数据——用自增序号丢弃过期响应。
  （云函数响应顺序没有保证，不能指望先发先回。）
- **后端本来就支持**：`analysis-svc monthBills` 早已接受任意 `payload.month`
  （含该月环比），本次**零云函数改动**，不需要 CODE_VERSION +1、不需要部署。
- **下月封顶当前月**：未来月份没有数据。置灰（`.nav-btn.disabled` +
  `atCurrentMonth` 数据）+ `onNextMonth` 内兜底 return。
- **空态文案按月份区分**：看历史月时弹「本月还没有记账，去记一笔」是错误引导
  （那个月已经过完了），改为「YYYY-MM 没有记账」且不显示记账引导。
- `shiftMonth('2026-01', -1) → '2025-12'` 放进 `utils/format.js`（跨年正确），
  与云函数侧同名工具对齐。

## 新契约测试：trend-detail-jump.test.js

这条链横跨 3 个文件，任何一环断了都是**静默失败**（就像原来只弹 toast 那样，
零报错）。按 trend-view.test.js 的做法**真解析源码**对账：

- 柱子必须绑 `data-month` + `bindtap="onTrendTap"`；
- `onTrendTap` 必须写 `detailMonth` 并 switchTab，且**不许再出现 showToast**
  （防占位实现回退）；
- 明细页 onLoad/onShow 必须消费且清空；loadBills 必须接受月份参数，
  且**不许在函数内 `new Date()` 重新推导当前月**（防写死回退）；
- 上/下月必须走 shiftMonth、下月必须封顶 currentMonth、不许 showToast；
- `shiftMonth` 跨年边界（2026-01-1 → 2025-12 等）。
